# card-produto-styled

Card de produto com CSS-in-JS usando Styled Components.

## Tecnologias

- React + Vite
- Styled Components

## Como rodar

git clone https://github.com/LucasAGomez/card-produto-styled.git
cd card-produto-styled
npm install
npm run dev
